# iOS App Folder

This folder is for Xcode-managed iOS app code.

## Current Contents
- `Starter/` contains copy/paste-ready SwiftUI starter files for API integration.

## When You Start on Mac
1. Create a new Xcode iOS App project in this `ios/` folder (or sibling path).
2. Copy `Starter` files into the app target.
3. Point the app to your Linux server IP.
